Selective by design

A filter, not an off switch.

Global “reduce motion” settings are useful, but websites don’t always listen. Low Motion adds a reversible policy only where you ask for it.

  1. 01

    Choose a site

    Open the extension on any regular webpage. Nothing changes elsewhere.

  2. 02

    Set the comfort level

    Pick Gentle, Balanced, or Still. The setting is remembered for that domain.

  3. 03

    Keep useful feedback

    Progress bars, live status, keyboard focus, and intentional changes remain clear.

Three calibrated profiles

As still as you need.

01

Gentle

Shortens animation and removes repeat loops. A softer first step for sites with useful transitions.

  • Short transitions
  • Single animation pass
  • Autoplay paused
02
Recommended

Balanced

Settles decorative motion while retaining a brief cue when interface state changes.

  • Loops effectively still
  • Brief state transitions
  • Autoplay paused
03

Still

Stops CSS animation and transitions for the quietest possible page, except explicit status.

  • No CSS animation
  • No transitions
  • Status still visible
10MIN
Balanced resumes

Temporary exception

Need the original motion for a moment?

Allow it for ten minutes, then your selected profile returns automatically. End the exception early at any time.

Private by default

Your browsing stays yours.

Profiles are stored locally in your browser. There are no accounts, analytics, remote rules, or browsing-history uploads.
